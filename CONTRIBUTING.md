# Contributing to Class Yearbook App

Thanks for your interest! This is a beginner-friendly project — all skill levels are welcome.

## How to Contribute

1. **Fork** this repository
2. **Clone** your fork: `git clone https://github.com/your-username/class-yearbook-app.git`
3. **Create a branch**: `git checkout -b fix/your-branch-name`
4. **Make your changes** — keep them focused and minimal
5. **Commit**: `git commit -m "fix: short description of change"`
6. **Push**: `git push origin fix/your-branch-name`
7. **Open a Pull Request** against the `main` branch

## Rules

- One issue per PR — keep changes focused
- Keep code simple and readable (no frameworks, no TypeScript)
- Write clear commit messages (e.g. `fix: card delete not working`)
- Test your changes by opening `index.html` in a browser before submitting

## Reporting Issues

Use the issue templates in `.github/ISSUE_TEMPLATE/` to report bugs or request features.
