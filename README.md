# 📚 Class Yearbook App

A simple web app to create and manage student profile cards. Built with plain HTML, CSS, and JavaScript — no frameworks, no build tools.

## Features

- Add students with a name, favorite snack, fun fact, and photo
- View all cards in a responsive grid
- Edit or delete any card
- Data persists in the browser via localStorage

## How to Run

1. Clone or download this repo
2. Open `index.html` in any browser

That's it — no install, no server needed.
